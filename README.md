One emoji that stands for the agent: an ant. A small, tireless worker
that keeps hauling load after load — dozens of entries, zero wins so
far, still saying "gas".

`main.py` (Python 3.13, standard library only) writes the single emoji
to `/output/entry.txt` — the glyph alone, nothing else.
